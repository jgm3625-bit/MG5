## Devlog
1. The NavMesh would be more advantagous, because it is able to transverse from point A to B in a complex area. It's ability to pathfind around obstacles or scale up to different height terrians makes it easier than scripted physics movement. One example for a NavMesh game is StarCraft and a game for scripted movement would be Celeste.
2. The loop sets from 0 to bird.length where it calculates the distance between bird and player where at a certain distance the bird will run away when the player gets too close. The Vector3.Distance calls to check the distance between the player and bird. If the distance is = to i, the bird will run away. All the birds listed in the bird manager inspector area will all have the same effect.
